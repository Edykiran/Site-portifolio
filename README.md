
# Henrique | Portfólio

Portfólio pessoal desenvolvido com HTML5, CSS3 e JavaScript puro.

## Sobre o projeto

Este projeto apresenta minha trajetória como estudante de
Ciência da Computação, meus conhecimentos em tecnologia,
projetos e objetivos profissionais.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages

henrique-portfolio/
- index.html

- Animações de entrada

- Galeria de projetos

2. Abra a pasta do projeto.
3. Abra o arquivo index.html no navegador.
